
# Blueprint: Интернет-магазин товаров для сада и отдыха

## Обзор

Этот проект представляет собой простой интернет-магазин, созданный с использованием Next.js и Firebase. Приложение позволяет пользователям просматривать товары из двух категорий - "Сад" и "Товары для отдыха", добавлять их в корзину и оформлять заказ, предоставляя свои контактные данные. При оформлении заказа менеджер получает уведомление в Telegram.

## Дизайн и стили

- **Основной макет:** Мы использовали корневой `layout.tsx` для создания единой структуры с шапкой (Header) и основным контейнером для контента.
- **Стили:** Для стилизации мы использовали Tailwind CSS. Цветовая схема основана на оттенках серого, с акцентным зеленым цветом (lime-500) для кнопок и интерактивных элементов.
- **Компоненты:**
    - `Header`: Содержит логотип, навигационное меню, иконку корзины, **общую сумму заказа**. Иконка профиля временно скрыта.
    - `Card`: Отображает информацию о товаре (изображение, название, цена) и кнопку добавления в корзину.
    - `CardList`: Отображает список карточек товаров.
    - `SidebarMenu`: Компонент гамбургер-меню, который появляется слева и содержит ссылки на категории товаров. Стиль меню обновлен, чтобы соответствовать общему дизайну сайта.

## Реализованные функции

- **Оптимизация производительности с помощью `unstable_cache`:**
    - Для решения проблемы с медленной загрузкой и избыточными запросами к базе данных при использовании `searchParams`, мы внедрили `unstable_cache`.
    - Три основных запроса к базе данных (`getCategories`, `getSubCategories`, `getProducts`) были вынесены в отдельные функции в `app/actions.ts`.
    - Каждая из этих функций обернута в `unstable_cache` с `revalidate: 600`, что позволяет кешировать результаты запросов на 10 минут.
    - Это значительно снижает нагрузку на базу данных и ускоряет загрузку страницы, так как данные теперь запрашиваются только при необходимости, а не при каждом посещении.
    - Директива `export const revalidate = 600` была удалена из `app/page.tsx`, так как кеширование теперь управляется на уровне отдельных функций.
- **Многоязычность:**
    - Реализована поддержка переключения языков (русский/английский) на всем сайте.
    - Интегрирован `LanguageContext` для управления текущим языком.
    - Обновлены типы данных (`Product`, `Category`, `ProductInCart`, `OrderItem`) для включения полей с английскими переводами (`title_en`, `category_en` и т.д.).
    - Модифицированы следующие компоненты для отображения контента на выбранном языке:
        - `ProductCard`: Карточки товаров.
        - `ProductDetailClient`: Страница детального просмотра товара.
        - `HomePageContent`: Главная страница (названия товаров, категорий, заголовки).
        - `CartPage`: Страница корзины (названия товаров и другие текстовые элементы).
        - `CategoryCarousel`: Карусель категорий.
        - `SidebarMenu`: Боковое меню (названия категорий и подкатегорий).
        - `OrdersPage`: Страница заказов.
        - `OrdersList`: Список заказов.
        - `CheckoutPage`: Страница оформления заказа.
    - Обновлена логика добавления в корзину для корректной работы с новыми типами данных.
- **Анимированная кнопка-гамбургер:** Стандартная иконка меню заменена на кастомную анимированную кнопку с эффектами свечения при наведении, которая превращается в крестик при открытии меню.
- **Адаптивные кнопки выбора соцсетей:** На странице оформления заказа кнопки выбора соцсетей были улучшены. Теперь они отцентрированы, адаптивны и при выборе окрашиваются в фирменные цвета (Telegram - синий, WhatsApp - зеленый, Facebook - синий), а также исправлена ошибка с появлением полей для ввода.
- **Гамбургер-меню:** В шапку сайта добавлено гамбургер-меню для удобной навигации по категориям. Меню стилизовано под общую темную тему сайта с акцентным лаймовым цветом.
- **Фильтрация по категориям:** На главной странице сохранены кнопки для фильтрации по категориям. Они будут в дальнейшем переработаны в карусель.
- **Просмотр товаров:** Пользователи могут просматривать товары на главной странице, загружая их из базы данных Firestore.
- **Пагинация:** На главной странице отображается не более 20 товаров, с возможностью перехода по страницам.
- **Страница продукта:** Реализована отдельная страница для каждого продукта с загрузкой данных из Firestore.
- **Отображение скидок:** Рядом с обычной ценой на товары теперь отображается перечеркнутая "старая" цена, которая на 120% больше исходной. Это создает видимость скидки и может стимулировать продажи. Изменения внесены в карточки товаров, на страницу детального просмотра товара и в корзину.
- **Корзина:**
    - Пользователи могут добавлять товары в корзину.
    - Содержимое корзины сохраняется в `localStorage`.
    - Создана страница корзины, где можно изменять количество товаров или удалять их.
    - В шапке сайта отображается иконка корзины с количеством товаров.
    - В шапке сайта, слева от иконки корзины, теперь отображается общая сумма заказа.
    - **Новое:** На странице корзины для управления количеством товаров добавлены кнопки "+" и "-", что улучшает пользовательский опыт на мобильных устройствах.
- **Рефакторинг типов данных:** По всему приложению был проведен рефакторинг `id` продукта — его тип был изменен со `string` на `number` для обеспечения консистентности данных и предотвращения ошибок типизации. Это включало обновление логики получения данных, определений типов и всех компонентов, использующих `id` продукта.
- **Структура URL:** URL-адреса страниц товаров были изменены и теперь включают категорию для улучшения SEO и навигации. Например: `/products/hiking/1`.

## План по улучшению SEO (Текущая задача)

**Проблема:**
1.  **Отсутствие заголовков:** На странице практически нет семантических заголовков (`<h1>`, `<h2>` и т.д.), что негативно сказывается на SEO и доступности.

**План действий:**

1.  **Улучшение структуры и SEO:**
    *   Добавить главный заголовок `<h1>` на главную страницу, который будет четко описывать ее содержание.
    *   Добавить подзаголовки `<h2>` для основных разделов страницы (например, для списков товаров).
